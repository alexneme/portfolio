# Dia 7 – Aprendendo uma Linguagem de Programação

![Linguagem de Programação](/images/programing-lang.png)

Chegamos à segunda fase do desafio: vamos falar de **linguagem de programação**.  
Para ser bem-sucedido no longo prazo como DevOps Engineer, é essencial conhecer pelo menos **uma linguagem em nível básico**.  

O objetivo desta semana não é virar desenvolvedor, mas entender o suficiente para ler código, saber como os times trabalham e até interagir melhor com as ferramentas do dia a dia.  

---

## Por que aprender programação?  

Se eu perguntasse nas redes se é preciso saber programar para atuar com DevOps, a resposta mais comum seria: **sim, precisa**.  
A dúvida maior é: **qual linguagem escolher?**  

As mais citadas são **Python** e, cada vez mais, **Go (Golang)**.  
O motivo é simples: grande parte das ferramentas de DevOps são escritas nessas linguagens.  

- Se você vai lidar bastante com **Kubernetes ou Containers**, faz sentido apostar em **Go**.  
- Se você busca automações rápidas e grande ecossistema de bibliotecas, **Python** é uma ótima opção.  

---

## Python ou Go?  

### Python  
- Interpretado: não precisa compilar para rodar.  
- Bom para scripts rápidos e automações menores.  
- Ecossistema enorme de bibliotecas.  

### Go  
- Compilado em **binários únicos** → sem depender de bibliotecas externas.  
- **Independente de plataforma** (Linux, Windows, macOS).  
- Alta performance, baixo consumo de CPU e memória.  
- Biblioteca padrão robusta: JSON, HTTP, concorrência, testes e muito mais já vêm de fábrica.  

É por isso que ferramentas como **Kubernetes, Docker, Grafana e Prometheus** foram escritas em Go.  

---

## Não é sobre ser dev  

Vale lembrar: o objetivo aqui não é virar desenvolvedor full-time.  
O ponto é **entender o que os devs estão fazendo**, ler código quando necessário e conseguir melhorar processos, pipelines e ferramentas.  

Você também vai se deparar com **arquivos de configuração** como Terraform (HCL) ou YAML — que não são linguagens de programação, mas são parte importante da rotina DevOps.  

---

## Escolha a sua trilha  

- Se você já está entrando em um time que usa Go, vá de Go.  
- Se você ainda não tem definição clara, Python pode ser mais acessível para começar.  
- O mais importante: escolha uma, comece, e siga aprendendo. Depois da primeira, as próximas ficam bem mais fáceis.
