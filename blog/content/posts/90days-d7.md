# Day 7 – Learning a Programming Language

![Programing Language](/images/programing-lang.png)

We’ve reached the second phase of the challenge: **programming languages**.  
To be successful long-term as a DevOps Engineer, you need to know at least **one programming language at a foundational level**.  

The goal this week isn’t to become a full-time developer, but to understand enough to read code, see how teams work, and interact more effectively with the tools we use every day.  

---

## Why learn programming?  

If I asked on social media whether you need programming skills for DevOps roles, most people would answer: **yes**.  
The bigger question is: **which language should you learn?**  

The most common answers are **Python** and increasingly **Go (Golang)**.  
The reason is simple: many DevOps tools are written in these languages.  

- If you’ll be heavily involved in **Kubernetes or Containers**, then Go makes a lot of sense.  
- If you want quick automations and a huge ecosystem of libraries, Python is a great choice.  

---

## Python or Go?  

### Python  
- Interpreted: no need to compile before running.  
- Great for quick scripts and small automations.  
- Huge ecosystem of libraries and frameworks.  

### Go  
- Compiles into a **single binary** → no external dependencies needed.  
- **Platform-independent** (Linux, Windows, macOS).  
- High performance with low CPU and memory usage.  
- Strong standard library: JSON, HTTP, concurrency, testing, and more built in.  

That’s why tools like **Kubernetes, Docker, Grafana, and Prometheus** were written in Go.  

---

## It’s not about being a developer  

Remember: the goal here isn’t to become a software developer.  
The point is to **understand what developers are doing**, read code when necessary, and improve processes, pipelines, and tools.  

You’ll also encounter **configuration files** like Terraform (HCL) or YAML — not programming languages, but essential in the DevOps workflow.  

---

## Choosing your path  

- If you’re joining a team that already uses Go, start with Go.  
- If you don’t have a clear direction yet, Python is an easier entry point.  
- What matters most: pick one, start learning, and keep going. Once you master the first, the next languages come easier.

Whether it’s one hour or three hours a day, the key is to **start and learn something new**.
